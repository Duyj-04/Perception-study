# 三维视觉与机器人算法学习记录

## 学习方向

| 方向 | 主要内容 | 计划完成的工作 |
|---|---|---|
| 深度估计与补全 | 单目相对和米制深度、双目匹配、稀疏深度补全、全景深度 | 建立评价基线，做受控对照，记录精度和部署开销 |
| 前馈三维重建与优化 | SfM、DUSt3R、MASt3R、VGGT、Ceres BA | 对比网络初值和 BA 结果，分析失败场景 |
| 3DGS 与神经渲染 | NeRF、高斯表示、可微光栅化、密度控制与压缩 | 完成已知位姿小场景重建，评测留出视角和资源开销 |
| 视觉惯性 SLAM | 几何状态估计、XFeat、IMU 预积分与系统鲁棒性 | 核验已有项目，开展系统对照和设备测试 |

数学、Python/PyTorch、C++、数值优化和性能分析贯穿这些方向。先完成小规模练习和基线，再结合岗位选择一个方向深入。

## 记录方式

论文笔记使用 [模板](02_papers/paper_note_template.md)，记录问题、方法、公式、实现和自己的疑问。每周可以从 [周记录模板](06_weekly/weekly_template.md) 开始，记下进展和下一步。

实验前先填写 [评价协议](05_experiments/protocol.md)，再用 [实验模板](05_experiments/experiment_template.md) 记录代码版本、数据、配置、设备、命令和结果。计划中的工作标明状态，失败结果也留下来。简历或面试中使用的数字需要能找到对应记录。

研究代码仍放在各自的原仓库中，这里保存入口和学习记录。数据集、模型权重、视频、构建产物和运行日志不提交；论文 PDF 也只保存在本地。部分个人计划、实验索引和生成的核验文件由 `.gitignore` 忽略，克隆仓库后不会自动包含这些本地文件。
