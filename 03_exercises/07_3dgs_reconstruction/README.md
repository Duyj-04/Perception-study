# 已知位姿 3DGS 最小重建练习

状态：计划，未执行。学习原版 3DGS 的表示、渲染和训练，先使用相机标定与位姿已知的静态小场景。

## 最小步骤

1. 用合成高斯说明中心、协方差、投影和两层 alpha 合成，检查颜色、可见顺序与有效参数约定。
2. 复用作者实现和受支持数据，固定 commit、相机、图像、初始化、迭代预算、种子和训练/留出视角。
3. 保存基线模型与留出视角，按固定色彩/背景/分辨率协议计算 PSNR、SSIM、LPIPS，另报告训练时间、渲染延迟、显存、高斯数量和文件大小。
4. 在相同相机和预算下只改变一个因素，如增密间隔或高斯预算。记录完整配置与质量—资源变化，不先许诺改善。

## 验收与边界

保留正常与失败视角、遮挡/细结构和泛化观察；训练视角画质不替代留出评价，渲染 FPS 不替代训练速度。没有独立几何 GT 时不声称几何精度已验证。与 [独立 3DGS 项目](../../04_projects/gaussian_reconstruction/README.md) 共用实验协议。
