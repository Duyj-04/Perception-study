# 前馈几何初值与 BA 练习

状态：计划，未执行。目标是比较网络预测、规范统一和几何优化后的结果，并解释收益或失败。

## 最小步骤

1. 先在小型合成多视图问题用 Ceres 等实现重投影 BA，核对坐标、内外参、Jacobian、固定的规范自由度及鲁棒损失。
2. 选择 DUSt3R/MASt3R/VGGT 的一个官方实现，登记输入图像、预处理、点图/深度、位姿和置信度定义；不能把点图全局对齐自动称作重投影 BA。
3. 复用官方可用导出与优化接口，构建网络初值→经核验的对应/三角化→BA。比较同一图像支持上的网络结果、几何优化前后及失败，不凭空假设网络支持任意 camera token 输入。
4. 固定数据与初值，只改变一个鲁棒权重、匹配预算或初始化因素；按验证集选定，最终在隔离测试集测几何、重投影和成本。

## 验收

保存低视差、光照变化、离群对应和动态物体等可获得反例；单纯训练残差下降不能证明几何更准。报告规范/尺度固定、位姿/深度/点云误差（有独立真值时）、有效支持和运行成本。可微 BA 与反馈网络属于后续研究候选。
