# 深度定义、双目与全景评价练习

状态：计划，未执行。目标是从几何与评价两端验证深度含义，配合 [基础专题](../../01_foundations/depth_estimation/README.md)。

## 最小步骤

1. 在有真实标定的双目数据或已知参数的合成场景上完成去畸变、校正和 SGBM，检查极线、无效视差、基线/像素单位及 $z=fB/d$ 的适用条件。
2. 在同一小型冻结数据划分上选择相对和米制模型，核对 checkpoint、深度/逆深度输出；相对模型按规定对齐，米制模型保留未经 GT 后验对齐的主结果。
3. 固定 GT mask、crop、范围和插值，计算 AbsRel、RMSE、δ1 及无效输出比例；以合成相同深度、已知倍数尺度和错误单位验证 evaluator。
4. 全景专题：检查 ERP↔Cubemap 射线往返、虚拟相机外参及径向距离/光轴深度转换，再选择全景模型；报告接缝和高纬区域，不直接将针孔模型视为兼容。
