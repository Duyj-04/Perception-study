# 这篇论文怎样边读边翻译

推荐先使用 **沉浸式翻译** 的浏览器扩展。以下按2026-11-08查阅的官方文档整理；不自动安装扩展或选择付费服务。

## 安装和划词

通过 [官方安装页](https://immersivetranslate.com/zh-Hans/docs/installation/) 选择Chrome或Edge等浏览器。启用扩展中的划词翻译后，选中词语/句子，再按实际设置触发翻译；具体触发方式和快捷键可在扩展中调整。参见 [官方划词说明](https://immersivetranslate.com/blog/select-and-translate-launch/)。

## 阅读这份 PDF

1. 在浏览器打开 [arXiv原文](https://arxiv.org/pdf/2406.09414v2)。
2. 点击扩展图标，选择翻译当前PDF。
3. 阅读本地PDF时，可从扩展的“更多”进入“翻译本地PDF文件”，再选择已下载文件。
4. 公式、表格或图中文字翻译不清楚时，回到原文核对，再参照中文精读稿；不要将机器翻译的模型名、单位和指标方向直接当作事实。

[官方PDF使用说明](https://immersivetranslate.com/zh-Hans/docs/features/pdf/) 区分标准PDF翻译和PDF Pro；公式/多栏等复杂内容的效果与所用模式、服务有关。可以先试标准PDF流程，再自行决定是否需要其他模式。

中文学习稿入口：[paper.md](paper.md)。原始PDF仍保持不变。
