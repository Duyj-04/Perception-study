# 求职作品集

计划：2027年7—8月整理完成，实际根据 2028 届正式校招窗口调整。

按岗位选择一个深入项目：深度估计/补全与部署、前馈重建与 BA，或已有 Learning-based VI-SLAM；同时为独立 3DGS 保留小型重建与留出视角结果。各分支先形成可复查基线，再按资源深化，MASt3R-SLAM/Photo-SLAM 为系统拓展。

每个项目最终至少有：

- 一页系统架构图（真实源码对应）；
- 两到四条清晰且可追溯的本人贡献；
- 公平对照表（含失败与局限）；
- 轨迹/地图/训练等可视化；
- 深度任务的尺度、补全支持与误差，重建任务的几何，3DGS 的留出视角质量（按任务选择）；
- 性能与资源测量、复现说明；
- 三分钟和十分钟口头讲述版本。
