# 3DGS、辐射场与新视角合成

3DGS 是独立的三维表示、优化和渲染学习主线。先用已知位姿的静态场景理解表示与训练，再研究位姿优化、深度先验、压缩及与 SLAM 的结合。当前未登记本专题实测。

## 从表示到训练

1. **NeRF 前置**：相机射线、可见性、密度/颜色、透射率和体渲染；区别几何表面、辐射场和新视角图像。
2. **高斯参数**：中心、尺度、旋转、透明度与颜色/球谐系数；解释各向异性协方差 $\Sigma=R\,\mathrm{diag}(s_x^2,s_y^2,s_z^2)R^T$ 及有效参数化。
3. **相机投影**：将协方差转到相机系，用局部投影 Jacobian 近似得到二维协方差 $\Sigma_{2D}\approx J\Sigma_{cam}J^T$；理解深度排序、椭圆 footprint 和视锥裁剪。
4. **合成与梯度**：按可见顺序对像素贡献做 $C=\sum_i c_i\alpha_i\prod_{j<i}(1-\alpha_j)$；有效 $\alpha_i$ 包含像素处高斯响应及透明度。追踪图像损失如何更新高斯参数。
5. **优化与密度**：理解颜色重建损失、位置/外观优化、克隆/分裂/裁剪与透明度管理；记录初始化、迭代数和密度控制策略。
6. **工程与扩展**：训练和渲染分开 profile；高斯数量、SH 阶数、压缩、分辨率与显存/延迟的关系。深度正则、位姿优化、动态场景及高斯 SLAM 在基线之后开展。

## 独立验收

- [ ] 用小型合成参数解释投影、协方差、遮挡和 alpha 合成；说明近似条件。
- [ ] 固定图像、标定和位姿，在公开小场景复现一个已知位姿重建基线。
- [ ] 训练与留出视角明确分离，按同一分辨率、颜色/背景和曝光规则报告 PSNR、SSIM、LPIPS 及失败图。
- [ ] 固定相机与训练预算，只改变一个密度/预算因素，报告质量—高斯数量—内存—训练/渲染耗时。
- [ ] 若有独立几何真值，再评价深度/点云准确性和完整性；没有几何真值时只报告实际可测的内容。

高质量新视角图像本身不证明几何或定位准确。几何评价还要明确参考坐标、尺度、可见范围及点云采样；训练视角的图像误差不替代留出视角结果。使用预测深度做监督时记录其来源和误差，不将该预测同时当独立真值。
