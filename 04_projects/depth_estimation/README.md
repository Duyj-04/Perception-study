# 深度估计、补全与部署项目

状态：2026-11-08 新增计划，尚未登记实现与实测。面向深度估计/补全 JD，目标是形成训练或调优、统一评价及部署证据。

## 阶段与交付

1. 按 [基础专题](../../01_foundations/depth_estimation/README.md) 定义任务与数据：单目相对/米制、双目、RGB+稀疏补全或 ERP 全景；先选一种作为核心，其余用小实验补齐知识。
2. 固定官方模型与小型公开数据基线，冻结单位、相机、mask、crop、split、对齐/深度范围和资源条件。优先复用已存在且经核验的结果。
3. 针对具体错误提出一个可证伪改动，如监督、采样、传播/置信度或模型预算；在验证集决定配置，报告测试集逐序列/逐场景结果和失败。
4. 选择一种可行的轻量化路径：分辨率/小模型、蒸馏、结构化剪枝或量化。比较原版与候选在同硬件、同输入和同精度协议下的开销，保持 GT 对齐规则不变。
5. 保存技术说明、深度/误差图、精度—延迟—内存曲线和复现记录；PC、导出验证与真实板端结果分别标识。

双目与全景分别检查校正/视差和球面深度/接缝。补全区与输入稀疏点分别评价；不同任务不能混成同一榜单。实验使用 [统一协议](../../05_experiments/protocol.md) 及 [结果索引](../../05_experiments/results_index.csv)。
