# 独立 3DGS 重建与渲染项目

状态：2026-11-08 新增计划，未登记实测。独立学习已知位姿三维表示、新视角合成及质量—资源权衡，再按岗位需要连接深度先验或位姿优化。

## 基线与对照

1. 先完成 [3DGS 基础](../../01_foundations/gaussian_splatting/README.md) 与 [最小练习](../../03_exercises/07_3dgs_reconstruction/README.md)，复用 [原版作者实现](https://github.com/graphdeco-inria/gaussian-splatting) 及受支持的小场景。
2. 固定数据、相机/位姿、初始化点、训练视角、独立留出视角、曝光/背景/分辨率、种子和迭代预算，保存全部配置。
3. 在相同条件下改变一个因素：增密/裁剪、最大高斯数或 SH 阶数。记录 PSNR/SSIM/LPIPS、高斯数、模型体积、峰值显存、训练时间与渲染 P50/P95；固定相机时先分析表示能力。
4. 扩展时再做深度正则、压缩或前馈/BA 相机初值对照；每次只有一个变化因素。预测深度不是独立几何 GT，不将相机改变与高斯参数改动混为一个因果结论。

## 交付与边界

保存留出视角和失败图、质量—预算表、训练和渲染计时说明。若有几何 GT，额外测深度/点云准确性、完整性及尺度；只有 RGB 真值时不宣称验证了几何精度。

不要求先跑通 MASt3R-SLAM 或 Photo-SLAM；它们是后续在线定位/地图维护拓展。使用 [统一实验协议](../../05_experiments/protocol.md) 和 [实验记录](../../05_experiments/experiment_template.md)。
