# 项目二：MASt3R-SLAM 复现与系统剖析

官方仓库（以运行时实际版本为准）：https://github.com/rmurai0610/MASt3R-SLAM

## 目标

理解几何基础模型先验怎样参与在线跟踪、点图对齐、关键帧、回环与图优化；形成精度、运行成本、失败模式的可复现分析。

## 计划顺序

1. 固定官方仓库 commit、模型 checkpoint、依赖及硬件。
2. 使用官方支持的针孔公开数据建立基线，先不改为全景输入。
3. 跟踪 pointmap / matching / tracking / graph / loop closure 的数据流。
4. 选择 **一个** 控制变量做系统消融（如回环或匹配预算）；保持其他条件固定。
5. 分析精度、失败、显存、延迟和尺度/坐标一致性。
